前面每一课都在用原理图，但每次只看三五个元件。真实产品的原理图上有几十上百个元件，还夹着大量缩写和记号。这一章教你把一张陌生的原理图拆开读懂。先从最基本的认起：符号、位号和数值。

## 符号画的是功能，不是外形

一只米粒大的贴片电阻、一只带引线的插件电阻、一块手指粗的水泥电阻，在原理图上是同一个符号。原理图只回答两件事：这是什么器件，它接在哪里。长什么样、多大、用什么封装，交给 PCB 和物料清单去管。

每个符号旁边一般有两行字：**位号**（R1）说明它是哪一只，**数值**（10k）说明它是多大。所有符号的样子可以随时去[符号速查](/symbols)页翻。

## 位号：一个字母说明是什么

| 字母 | 器件 | 例子 |
| --- | --- | --- |
| R | 电阻 | R1 10k |
| C | 电容 | C3 100n |
| L | 电感 | L1 4.7 μH |
| D | 二极管、LED | D1 SS34 |
| Q | 三极管、MOSFET | Q1 S8050 |
| U | 集成电路 | U1 STM32F103 |
| J、P | 连接器、排针 | J1 USB |
| SW | 开关、按键 | SW1 |
| Y | 晶振 | Y1 8 MHz |
| F | 保险丝 | F1 500 mA |
| TP | 测试点 | TP1 |
| BT | 电池 | BT1 CR2032 |
| K | 继电器 | K1 |

字母后面的数字是同类器件的编号。物料清单（BOM）和 PCB 上的丝印都用同一个位号，在三者之间对照全靠它。个别字母各家习惯不同，比如晶振也有人写 X，磁珠常写 FB。

## 数值的写法

原理图上的数值经常省掉单位，还会把小数点换成字母：

| 写法 | 意思 | 说明 |
| --- | --- | --- |
| 4k7 | 4.7 kΩ | 前缀字母占小数点的位置，图纸印糊了也不会把 4.7k 看成 47k |
| 2R2 | 2.2 Ω | R 当小数点用 |
| 0R | 0 Ω | 零欧电阻，当跳线或预留的选择开关用 |
| 100n | 100 nF | 电容省掉 F |
| 10u/16V | 10 μF，耐压 16 V | 需要时把耐压、精度写在后面 |
| NC、DNP | 不焊 | 预留位置，生产时空着 |

## 极性和 1 号引脚

有极性的器件接反就不工作，有的还会损坏。原理图上这样标：

- **电解电容**：「+」号一侧接高电位。
- **二极管、LED**：三角形指向的竖线一端是负极，对应实物丝印上的那道杠。
- **电池**：长线是正极。
- **芯片**：原理图上的引脚按功能排列，跟实物的位置无关，引脚旁的小数字才是引脚号。实物上用圆点或缺口标出 1 号脚。

符号的引脚号和封装的焊盘号必须一一对上。这一步出错，原理图看着全对，板子却是错的。

## 国标和美标

同一个器件，不同标准画法不同。最常碰到的是电阻：

<SymbolStylesFigure />
</Figure>

| 器件 | 美标（ANSI） | 国标、IEC |
| --- | --- | --- |
| 电阻 | 折线 | 空心矩形 |
| 电解电容 | 一块直板加一块弯板 | 两块板，标「+」 |
| 逻辑门 | 与门、或门各有特定外形 | 统一画矩形，里面写 & 或 ≥1 |

国内教材和国标图纸用矩形，芯片厂的参考设计和开源硬件多用折线，两种都要认得。本站一律画折线。

## 同一个器件，几种画法

<Figure caption="MOSFET 画不画体二极管；一颗双运放拆成两个单元">
<SymbolVariantsFigure />
</Figure>

- **MOSFET** 的简化画法省掉了体二极管，完整画法把它画出来。体二极管在功率 MOSFET 里总是存在，画不画都在。
- **多单元器件**：一颗 LM358 里有两个运放，原理图上常拆成 U1A、U1B 分开画在用到的地方，电源脚有时再单独画成一个单元。它们在板上是同一颗芯片。
- **大芯片**按功能拆成几块：电源一块、GPIO 一块、调试接口一块。

## 电源和地的符号

<Figure caption="电源符号和几种地">
<PowerGroundFigure />
</Figure>

**电源符号**是一小段横线加名字（3V3、5V、VCC、VBAT）。名字相同的电源符号全部连在一起，不必画线。地也一样：所有 GND 是同一个网络。

有的板子把地分开命名：**AGND**（模拟地）给 ADC 和传感器，**PGND**（功率地）给大电流回路。名字不同就是不同的网络，通常只在一点用 0 Ω 电阻或磁珠连起来。**机壳地**接金属外壳和屏蔽层。

<Warn title="名字差一个字也不连">
3V3 和 3.3V、GND 和 Gnd，在 EDA 软件里是两个网络。画图时名字要统一，读图时看到两种写法要留心：它们可能本来就没连上。
</Warn>

## 小结

- 符号表示功能和连接，不表示外形和位置。
- 位号的字母说明器件种类（R、C、L、D、Q、U、J、SW、Y、F、TP、BT、K），原理图、BOM、PCB 靠位号对应。
- 4k7、2R2、100n：前缀字母或 R 当小数点；0R 是零欧电阻，NC、DNP 是不焊。
- 电阻有美标折线和国标矩形两种画法；MOSFET 可能省略体二极管；多单元器件拆成 U1A、U1B。
- 同名的电源符号、地符号都连在一起；名字不同就不连。
