认得每个符号，还不等于读得懂一张图。一块单片机板子有几十个元件，从左上角一个个看下去很快就迷路。这一课讲两件事：图上的记号是什么意思，按什么顺序读。

## 原理图只画连接关系

原理图表达的是「谁和谁相连」，不表达元件在板子上的位置。图上挨着的两个元件，板子上可能隔着十厘米；一根线画得多长、拐几个弯，也没有任何意义。

所以画图的人按功能分块、按信号流向排列，怎么好读怎么摆。读图时别去想「它在板子哪里」，只看它连到哪里。

## 网络标号：不画线也相连

电气上连在一起的所有点合起来叫一个**网络**（net），每个网络有一个名字。**网络标号**就是贴在线上的这个名字：名字相同的标号属于同一个网络，即使中间一根线都没画。

隔得远的信号用标号连，图面就不会被长线和交叉线挤满。上一课的电源符号和地符号，其实就是特殊的网络标号。

原理图上常见的记号：

| 记号 | 意思 |
| --- | --- |
| 同名的网络标号 | 相连 |
| 同名的电源符号、地符号 | 全部相连 |
| 交叉的两根线，交点有圆点 | 相连 |
| 交叉的两根线，没有圆点 | 不相连，只是跨过去 |
| 引脚末端画一个叉 | NC（no connect），故意不接 |
| TP 加一个小圆圈 | 测试点：板上留一块焊盘，给万用表、示波器探头用 |
| 一根粗线，分支上各有标号 | 总线：一组同类信号，如 D0–D7 |
| 带箭头的标号，旁边写页码 | 跨页连接：信号接到另一页图纸 |

多页的原理图里，只在本页有效的局部标号不会跨页，要跨页得用全局标号或端口。各家 EDA 软件的规则略有不同，读图时留意标号的形状。

<Tip title="好图纸不画十字连接">
四根线交在一点、再点一个圆点，印糊了就分不清连没连。规范的画法是把相连的线错开成两个 T 形，各点一个圆点；十字交叉只用来表示「不相连」。
</Tip>

## 按功能块读

拿到一张图，按这个顺序过一遍：

| 顺序 | 找什么 | 为什么 |
| --- | --- | --- |
| 1 | 电源从哪进来，变成了几路电压 | 每个芯片在什么电压下工作，全看这里 |
| 2 | 地 | 确认每个芯片和接口都接了地 |
| 3 | 主芯片 | 全图的中心，其他部分都围着它 |
| 4 | 输入 | 按键、传感器、ADC：信号从哪里进来 |
| 5 | 输出 | LED、继电器、电机：芯片控制什么 |
| 6 | 通信 | I²C、SPI、UART：芯片和谁说话 |

## 画图的习惯

大部分原理图遵守同样的习惯：

- **信号左进右出**：输入接口在左，输出在右，电路从左往右处理信号。
- **电源在上，地在下**：电压高的画在上面，地符号朝下。
- **一个功能一块**：电源、单片机、接口各占一块，常用虚线框起来写上标题。
- **芯片旁的小电容**几乎都是去耦电容，100 nF 居多。
- **引脚名和网络名不同**：PC1 是芯片的引脚名，SDA 是这根线的网络名。

## 对照 BOM 和 PCB

原理图、BOM、PCB 三者靠位号对应。原理图上看到 R3，在 BOM 里查到它是 10 kΩ、0603 封装，在 PCB 丝印上找到印着 R3 的那个位置。

KiCad、立创 EDA 都支持**交叉探测**：在原理图里点一个元件，PCB 上同一个元件跟着高亮，调试时靠它从图纸找到板上的位置。标着 NC 或 DNP 的元件，板上空着是正常的。

## 读开源硬件

练读图最好的材料是公开的开发板原理图：Arduino Uno、树莓派 Pico、ESP32-DevKitC 都能在官网下载到。

- 先看首页的框图或目录，弄清分了几页、每页管什么。
- 带着问题读：它怎么供电？程序怎么下载进去？哪些引脚引出来了？
- 对照主芯片数据手册里的典型应用电路。开发板的大部分外围电路都是从那里照搬的。

## 小结

- 原理图只表达连接关系，元件在图上的位置和线的长短都没有意义。
- 同名的网络标号、电源符号、地符号相连；交叉线有圆点才相连；NC 是故意不接。
- 读图顺序：电源 → 地 → 主芯片 → 输入 → 输出 → 通信，把整张图拆成认识的小块。
- 习惯上信号左进右出、电源在上地在下；芯片旁的小电容多半是去耦。
- 原理图、BOM、PCB 靠位号互相对照。
