三极管当开关有个麻烦：负载电流越大，基极要喂的电流就越多。**MOSFET**（场效应管）换了个思路，用电压来控制，控制端几乎不要电流。从手机里的电源开关到电动车的电机驱动，今天的开关电路大多用它。

## 三个脚：G、D、S

MOSFET 的三个脚是**栅极**（G）、**漏极**（D）和**源极**（S）。栅极是控制端，大电流在漏极和源极之间流过。

| MOSFET | 相当于三极管的 | 作用 |
| --- | --- | --- |
| 栅极 G | 基极 B | 控制 |
| 漏极 D | 集电极 C | 接负载 |
| 源极 S | 发射极 E | N 沟道接地，P 沟道接电源 |

它也分两种：**N 沟道**（N-MOS，对应 NPN）和 **P 沟道**（P-MOS，对应 PNP）。

## 用电压控制

栅极和管子里的导电沟道之间，隔着一层极薄的绝缘层。栅极就像一只小电容的极板：加上电压，沟道形成；电压保持着，管子就一直导通，不需要持续的电流。

这只**栅极电容**（几十 pF 到几 nF）带来两个后果：

- 稳态下栅极电流几乎是 0，单片机引脚可以直接驱动。
- 每次开关都要给它充电、放电。开关得越快、越频繁，驱动电路要出的瞬时电流越大。

## 两个关键参数

**阈值电压** $V_{GS(th)}$：栅极比源极高出这个电压，沟道才**开始**形成。手册通常按漏极电流只有 250 μA 来定义它，离完全导通还差得远。

**导通电阻** $R_{DS(on)}$：完全导通后，漏极和源极之间相当于一只很小的电阻，一般是几毫欧到几十毫欧。它和栅极电压有关，所以手册总带着条件写，比如「30 mΩ @ $V_{GS}$ = 4.5 V」。

导通时管子的发热，就是这只电阻的发热：

$$
P = I_D^2 \times R_{DS(on)}
$$

**例：** 2 A 流过 33 mΩ，$P = 2^2 \times 0.033 \approx 0.13\ \text{W}$，贴片小管子不加散热片也没问题。

## N 沟道低边，P 沟道高边

- **N-MOS 做低边开关**：源极接地，负载接在电源和漏极之间，栅极给高电平导通。最常用。
- **P-MOS 做高边开关**：源极接电源，栅极拉低导通。和 PNP 一样，电源电压高于单片机电压时关不断，要再加一只小 N-MOS 或 NPN 去拉它的栅极。

MOSFET 的结构里天生带着一只二极管，叫**体二极管**。N-MOS 的体二极管从源极指向漏极。它意味着 MOSFET 只挡得住一个方向：电压反过来，电流直接从体二极管里穿过去。

- **下拉电阻**（10 kΩ–100 kΩ，栅极到源极）：单片机上电、复位的那一小段时间，引脚是悬空的，栅极只要感应到一点电荷，管子就可能自己打开。下拉电阻保证这时栅极是 0 V。
- **串联电阻**（几十到一百欧）：限制给栅极电容充放电的瞬时电流，保护引脚，也减轻开关瞬间的振荡。
- 负载是电机、继电器这类电感时，续流二极管照样不能少。

<Warn title="栅极很娇气">
栅极的绝缘层非常薄。栅源电压超过手册的最大值（常见 ±12 V 或 ±20 V）会把它永久击穿，人体静电也做得到。拿取和焊接时别用手碰引脚，电路里的栅极不要悬空。
</Warn>

## 选型看什么

| 参数 | 怎么看 |
| --- | --- |
| 耐压 $V_{DS}$ | 至少是电源电压的 1.5–2 倍，感性负载会有尖峰 |
| 最大电流 $I_D$ | 手册上的值是理想散热下的，实际按一半以下用 |
| $R_{DS(on)}$ | 看和你的驱动电压对应的那一行，再用 $I^2 R$ 算发热 |
| $V_{GS(th)}$ | 它的最大值要明显低于你的驱动电压 |

## 和三极管比

| | 三极管（BJT） | MOSFET |
| --- | --- | --- |
| 控制方式 | 基极电流 | 栅极电压 |
| 维持导通要的电流 | 负载电流的 1/10 左右 | 几乎为 0 |
| 导通时的损耗 | $V_{CE} \times I_C$，压降 0.1–0.3 V | $I_D^2 \times R_{DS(on)}$，通常小得多 |
| 适合的电流 | 1 A 以内 | 几十毫安到上百安 |
| 最怕 | 基极电流不够，掉出饱和 | 栅极电压不够，半开；静电 |
| 典型用途 | 小继电器、蜂鸣器、指示灯 | 电机、灯带、电源开关 |

## 小结

- MOSFET 用栅极电压控制，稳态几乎不取电流；但栅极有电容，每次开关都要充放电。
- $V_{GS(th)}$ 只是开始导通的电压。是否完全导通，要看手册在指定 $V_{GS}$ 下给出的 $R_{DS(on)}$。
- 导通发热 $P = I_D^2 \times R_{DS(on)}$。3.3 V、5 V 直接驱动要选逻辑电平管。
- N-MOS 做低边开关，P-MOS 做高边开关；体二极管让它只挡得住一个方向。
- 栅极配下拉电阻和串联电阻，感性负载加续流二极管。
