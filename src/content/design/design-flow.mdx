前面的课教的是零件和单元电路。这一课把它们排成一条流水线：从一句需求出发，到一块能工作的板子为止。全程用同一个小项目来讲：一只电池供电的温湿度记录器。

## 先把需求写成数字

「做个温湿度计」不算需求。**需求**要回答五个问题，每个答案都带数字：

| 问什么 | 温湿度记录器的答案 |
| --- | --- |
| 功能 | 每分钟测一次温湿度，存进 Flash，用串口导出 |
| 供电 | 一颗 CR2032 纽扣电池，要用满一年 |
| 尺寸 | 板子不超过 40 mm × 30 mm |
| 成本 | 物料 30 元以内 |
| 环境 | 室内，0–50°C |

后面每做一个决定，都回来对照这张表。

## 画框图，选关键器件

**系统框图**把需求拆成几个方块：一个方块一个功能，连线上写清接口和电压。这一步不管具体怎么接线，只确认有哪几块、它们之间怎么说话。

| 资料 | 手册全不全，有没有例程 |
| 参考设计 | 有没有官方开发板的原理图可以照着画 |

## 动手之前先算功耗

「一颗纽扣电池用一年」做不做得到，画图之前就能算。电池供电的设备大部分时间在休眠，隔一阵醒来干一小会儿活。设每隔 $T$ 醒来一次，每次工作 $t_{on}$，平均电流是两段的加权平均：

$$
I_{avg} = I_{run} \times \frac{t_{on}}{T} + I_{sleep} \times \left(1 - \frac{t_{on}}{T}\right)
$$

单片机运行 5 mA、休眠 2 μA，每 60 s 醒来 0.2 s：

$$
I_{avg} = 5\ \text{mA} \times \frac{0.2}{60} + 2\ \mu\text{A} \approx 16.7\ \mu\text{A} + 2\ \mu\text{A} = 18.7\ \mu\text{A}
$$

加上传感器的 3.5 μA，一共约 22 μA。续航等于容量除以平均电流：220 mAh ÷ 0.022 mA ≈ 9900 小时，约 413 天。

<PowerBudgetLab />

打开常亮的指示灯，或者让单片机不休眠，续航立刻从一年掉到几天。在纸上发现这种问题，比在板子上发现便宜得多。

<Tip title="稳压器自己也耗电">
常见的 AMS1117 静态电流约 5 mA，是整个系统休眠电流的上千倍。电池供电要选静态电流只有几微安的 LDO，或者让 3 V 电池直接供电。
</Tip>

## 画原理图，逐项检查

原理图不从白纸画起：把参考设计和每个器件手册里的典型应用电路拼起来，再按需求修改。画完先别画板，照清单过一遍：

| 检查项 | 看什么 |
| --- | --- |
| 电源 | 每一路电压对不对，电流够不够，有没有防反接 |
| 去耦 | 每个电源脚旁边有 100 nF |
| 上拉 | I²C、复位、开漏输出有没有上拉电阻 |
| 未使用的引脚 | 按手册处理，输入脚不悬空 |
| 调试接口 | 下载口和串口引出来了吗 |
| 测试点 | 电源和关键信号留了下表笔的地方 |

## 从 PCB 到上电

接下来是 PCB 布局布线、规则检查、打样、焊接、上电调试，再把发现的问题改进下一版。每一步交出什么、容易错在哪儿，点开看：

<DesignFlowLab />

画原理图和 PCB 用 **EDA** 软件，常见的有三个：

| 软件 | 特点 |
| --- | --- |
| KiCad | 免费开源，三大操作系统都能用 |
| 立创 EDA | 免费，浏览器里就能画，器件库和采购、打样连在一起 |
| Altium Designer | 商业软件，公司里常见 |

EDA 还能导出 **BOM**（物料清单）：每个器件的型号、封装、数量。采购和算成本都靠它。

<Warn title="第一次上电">
用可调电源，电流上限设在几十毫安。先只焊电源部分，量到电压正确，再焊其余的，一块一块通电。直接装电池，哪里一短路就只能看着它冒烟。
</Warn>

<Tip title="先验证，再画板">
没把握的电路，先用开发板加面包板搭出来跑通。打一次样要等几天，面包板上改一根线只要几秒。
</Tip>

## 小结

- 流程：需求 → 框图 → 选型 → 原理图 → 检查 → PCB → 打样焊接 → 上电调试 → 迭代。
- 需求写成数字；选型看供货、封装、资料、参考设计。
- 电池供电先算功耗：平均电流是工作和休眠两段的加权平均，续航 = 容量 ÷ 平均电流。
- 原理图从参考设计和手册的典型电路出发，画完按清单检查。
- 第一次上电用限流电源，分块通电；没把握的电路先在面包板上验证。
