I²C 省线，但几百 kHz 的速率刷不动一块彩屏，也读不快一颗 Flash。需要速度的地方用 SPI：多花几根线，换来几十倍的速率。

## 四根线

| 信号 | 方向 | 作用 |
| --- | --- | --- |
| SCK | 主机 → 从机 | 时钟，由主机产生 |
| MOSI | 主机 → 从机 | 主机发出的数据 |
| MISO | 从机 → 主机 | 从机发回的数据 |
| CS | 主机 → 从机 | **片选**，拉低表示「现在和你说话」 |

发和收各有一根线，可以同时进行，这叫**全双工**。有的手册把 MOSI、MISO 写作 SDI、SDO 或 DIN、DOUT，把 CS 写作 SS、NSS，是同一回事。

## 本质：两个移位寄存器首尾相接

「触发器与时序逻辑」一课里的移位寄存器，在这里派上了用场。主机和从机各有一个 8 位移位寄存器，MOSI 和 MISO 把它们连成一个环。每来一个时钟，两边各移出一位、移入一位；8 个时钟之后，两个字节正好互换。

<SpiLab />

所以 SPI 没有单独的「读」。主机想读一个字节，也得发一个字节出去（通常发 0x00 或 0xFF 占位），顺便把从机的数据换回来。

## 四种模式

时钟空闲时是高还是低（**CPOL**），在每个周期的第几个沿采样（**CPHA**），组合出四种模式：

| 模式 | CPOL | CPHA | 时钟空闲 | 采样沿 |
| --- | --- | --- | --- | --- |
| 0 | 0 | 0 | 低 | 上升沿（第一个沿） |
| 1 | 0 | 1 | 低 | 下降沿（第二个沿） |
| 2 | 1 | 0 | 高 | 下降沿（第一个沿） |
| 3 | 1 | 1 | 高 | 上升沿（第二个沿） |

数据在一个沿上被采样，在另一个沿上换成下一位。主机和从机的模式必须一致，以器件手册的时序图为准。多数器件用模式 0 或模式 3，这两种都在上升沿采样。

## 片选、速率和局限

- **每个从机一根片选。** 没被选中的从机把 MISO 置为高阻，让出这根线。挂 n 个从机要 3 + n 根线。
- **快。** 信号线是推挽输出，不用等上拉电阻慢慢充电，常见速率从几 MHz 到几十 MHz。
- **没有地址，也没有应答。** 从机不在线，主机照样把时钟发完，读回来的是全 0 或全 1。
- **走不远。** 速率高，线一长波形就变差，一般只在同一块板上或十几厘米的排线内用。

## 三种接口放在一起

| 对比 | UART | I²C | SPI |
| --- | --- | --- | --- |
| 信号线 | 2 | 2 | 3 + 每个从机 1 根 |
| 时钟 | 没有，靠约定波特率 | SCL | SCK |
| 常见速率 | 9600–115200 bit/s | 100–400 kbit/s | 1–50 Mbit/s |
| 能连几个 | 2 个，点对点 | 很多，按地址 | 几个，按片选 |
| 应答 | 无 | 有 | 无 |
| 典型器件 | GPS、蓝牙模块、调试口 | EEPROM、传感器、小 OLED 屏 | Flash（W25Q64）、SD 卡、TFT 屏 |

## 小结

- SPI 用 SCK、MOSI、MISO 加每个从机一根片选，主机产生时钟，全双工。
- 本质是两个移位寄存器首尾相接：8 个时钟，主从各交换一个字节。
- CPOL 定时钟的空闲电平，CPHA 定在第几个沿采样；多数器件用模式 0 或模式 3。
- 速率可到几十 MHz，但没有地址和应答，只适合板内的短距离连接。
- 要速度选 SPI（Flash、SD 卡、屏幕），要省线选 I²C，点对点和调试用 UART。
