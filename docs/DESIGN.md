# 设计

基于 jim-uiux 1.10.1（见 https://github.com/linjiejim/jim-uiux）。本文只记录与默认值不同的地方。

## 旋钮

- 皮肤：默认
- 强调色：默认黑色
- 圆角：默认 8
- 密度：舒适
- 默认外观：跟随系统。侧栏底部只放浅色、深色两个选项；没选过就跟着系统走，选了和系统当前相同的那个，就交回给系统

## 在 kit 之上加的东西

都在 `src/index.css` 和 `src/lab/`，只用主题里的 token，没有新增颜色、字号、圆角。

- `.lesson`：课程正文的排版。长文按 `text-reading`（16 / 26）阅读，一行不超过 680px。
- `.lab-range`：交互组件用的滑块。kit 里没有滑块，这里按输入控件的规格做了一个：轨道 4px、强调色填充、焦点环和 kit 一致，触屏上滑块头 24px、整体高 44px。
- `src/lab/`：交互工具包（外框 `Lab`、曲线图 `Plot`、时序图 `Timing`、电路图 `Schematic` 和元件符号）。外框是一张 1px 细线的平卡片，各部分用细线分隔，不套卡片。

## 数据颜色

课程里的颜色有固定含义，取自主题的分类色（数据色，不是第二个强调色），定义在 `src/lab/colors.ts`：

| 含义 | 分类色 |
| --- | --- |
| 电压、高电平 | orange |
| 电流（导线上流动的点） | blue |
| 功率、发热、损耗 | red |
| 第二、三、四路信号 | purple、teal、pink |
| 在允许范围内、目标值 | green |

颜色从不是唯一的信号：曲线有图例，读数有文字标签，状态有图标和文字。

## 例外

- 物理量的数字和单位之间加空格（`4.7 kΩ`、`100 nF`），遵循国际单位制的写法，而不是 content.md 里「数字与单位之间不加空格」的界面规则。百分号和角度仍然不加（`50%`、`90°`）。
- 课程页的标题用 `text-display`（28），比页面标题默认的 22 大一级：这是长文阅读页，标题下面紧跟的是 22 的小节标题。
- 首页是营销页，用了 `text-hero` 和一句说明文字。
- 工具箱（`/tools/<id>`）用列表-详情分栏，但左栏是工具选择器而不是待处理的队列：固定 240 宽、不能拖，当前工具和侧栏导航一样用 `pressed` 填充（不是 `selected`）。详情栏最宽 720，每个工具在 1280 × 720 的窗口里不用滚动。
- `src/widgets/components/ColorCodeLab.tsx` 里电阻色环的颜色写的是实物色值（带 `design-allow` 注释）：它们是被教的内容本身。
- 仿真动画（导线上流动的电流、波形）属于内容而不是界面动效，不受 120–240ms 的限制；组件滚出屏幕时自动暂停，系统开了「减少动态效果」时循环动画默认不播放。
- 课前动画讲解（`src/films/`）的舞台按视频处理：画面整体按宽度缩放，舞台里的文字不受 12px 下限约束（手机上会小，和看视频一样，可以全屏）。字幕、文字稿和播放控件是正常的界面文字，守 12px 下限。动画由用户点播放才开始，「减少动态效果」时保留淡入淡出、去掉位移。电阻色环等实物颜色同上，写实物色值并加 `design-allow` 注释。
